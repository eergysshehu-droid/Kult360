This is not a perceptual duplicate guarantee. Visual/crop variants with different Wix IDs can still exist and require review.

## Blocking editorial issues

- Team roles are mapped, but extracted biographies are missing for the five people records.
- Journal inventory contains 31 items, but full article bodies are not bundled in Phase 2. No article should be published from metadata alone.
- Projects explicitly flagged for impact/causality or recognition verification remain review-only.
- Testimonials require original wording/permission review before republication.
- Media rights are not assumed from public availability. Rights/credit review remains mandatory.
- Legacy Lab and Gallery page bodies remain incomplete in the extraction.
- Heritage contains legacy placeholder content and must be editorially rebuilt rather than copied verbatim.

## Localization

Source-language material is preserved. Missing EN/SQ variants remain pending. Phase 3 does not generate translations.

## CMS status

No Sanity connection or write is part of this package. Before an import file is generated, the conceptual map must be compared to the exact Studio schemas created in Phase 1.
