# KULT360 — Phase 4 Editorial Design

This patch is visual/product design only. It assumes the Phase 3 local-content build is already green.

## Direction

- contemporary European cultural institution / editorial archive
- warm paper canvas, near-black ink, controlled KULT360 yellow
- large editorial serif typography paired with restrained sans metadata
- asymmetric project rhythm rather than a uniform card grid
- image-led project and journal hierarchy
- numbered institutional sections and people/partner indexes
- restrained interaction and motion with reduced-motion support
- mobile-first hierarchy with no hover dependency

## Files changed

- homepage EN/SQ composition
- header and mobile navigation
- footer
- project and journal cards
- design tokens, typography and global responsive system
- BaseLayout theme color

## Deliberately not included

- no Sanity or CMS
- no production deployment
- no domain changes
- no content invention
- no new external font dependency
- no final visual-regression baseline update

Phase 5 should handle accessibility regression, performance, redirects, SEO/content QA and final visual baselines after the visual direction is approved.
